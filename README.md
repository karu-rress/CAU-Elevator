# CAU Elevator

중앙대학교 310관 엘리베이터 지도 앱입니다.  

100주년기념관 및 경영경제관(310관) 내부에 있는 13대의 엘리베이터의 위치와 운행 범위를 확인할 수 있습니다.

## 사용 방법
출발 층과 목적지를 선택하면 해당 층으로 갈 수 있는 엘리베이터를 추천합니다. 지도 화면에서 전체 엘리베이터의 위치를 조회할 수 있습니다.

## 엘리베이터 목록
- 1호기: (지상) 1, 3, 5, 7, 9층 운행
- 2호기: (지상) 1, 2, 4, 6, 8층 운행
- 3호기: (전층 하부) B6~B3, 1, 3, 6, 9층 운행
- 4호기: (전층 하부) B6~9층 운행
- 5호기: (전층 하부) B6~9층 운행
- 6호기: (전층 상부) B3~12층 운행
- 7호기: (전층 상부) B3~1, 3, 6, 9, 12층 운행
- 8호기: (지상) 1, 5, 8, 11층 운행
- 9호기: (지상) 1, 4, 7, 10층 운행
- 10호기: (전층 상부) B3~12층 운행
- 11호기: (전층 상부) B3~1, 3, 6, 9층 운행
- 12호기: (전층 상부) B3~12층 운행
- 13호기: (대형강의실 전용) B6(강의실)~B5 운행
